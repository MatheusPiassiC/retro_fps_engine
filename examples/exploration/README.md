# Demonstração de exploração

Espaço reservado para a aplicação externa que utilizará a engine em M5.

O exemplo importará `retro_fps` após a instalação do pacote e receberá um caminho de mapa, sem copiar raycasting, colisões ou projeção. Ainda não há aplicação executável nesta pasta.

A entrega mínima será explorar um cenário. Objetivos e condições de vitória, se adicionados, serão implementados aqui ou em outro exemplo, mantendo o núcleo reutilizável.
